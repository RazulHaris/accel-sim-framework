## Metric definitions (Block 3 of the workbook)

| item | definition | source |
|---|---|---|
| IPC gain vs no prefetching | gpu_tot_ipc(version) / gpu_tot_ipc(no prefetching, same GPU setup, cap and workload) − 1 | sim.out |
| Best kernel (Diagnostic) | per workload, the kernel function with the largest IPC ratio among kernels with >= 1% of the no-prefetch run's cycles; kernel IPC = instructions / cycles over its launches (paired in order). At 1B the launch cut by the cap is excluded; at 100M it is kept (it is the only launch of backprop and hotspot 1024). Biased upward by selection: diagnostic only. | K1_best_kernel.md, kernel_gap.py |
| Perfect-L1 ceiling | IPC with -gpgpu_perfect_l1d 1 / no-prefetch IPC − 1 (every L1-cached global load hits); run only at PAPER_V100 and PAPER_LAT, 1B | D1_ceilings.md |
| Coverage, Snake-paper style (coverage_pred) | demand sectors an earlier prediction named (issued or not, within 5,000 cycles) / demand sectors (GLOBAL_ACC_R accesses not failing with RESERVATION_FAIL) | Snake paper §4 ('correctly predicted addresses / total demand addresses'); SPEC OQ-14 |
| Delivered coverage | (timely + late prefetched sectors) / demand sectors (coverage_paper) | SPEC OQ-14 |
| Accuracy, Snake-paper style (accuracy_paper) | timely prefetched sectors / demand sectors: timely coverage, not useful / issued | Snake paper §4 ('timely correctly predicted addresses'); SPEC OQ-14 |
| SnakeCharmer coverage H/(H+M) | H = loads hitting a prefetched sector (on-time) [+ late merges in the second column]; M = loads sending a new request (late counted in M in the first column) | SnakeCharmer §II-B, Fig. 12 caption; SPEC OQ-36 |
| SnakeCharmer accuracy H/F | (on-time uses + fills a load had merged into) / prefetch fills ((sc_ld_ontime + sc_pf_fills − pf_filled) / sc_pf_fills) | SnakeCharmer §II-B; SPEC OQ-36 |
| On time / too early / too late | shares of consumed prefetches (first load): hit after the fill / evicted unused earlier in the kernel / merged into the in-flight MSHR entry | SnakeCharmer §II-B, Fig. 4; SPEC OQ-36 |
| Prefetch-induced demand evictions | demand-filled victim sectors evicted by a prefetch allocation / all valid victim sectors | SnakeCharmer §II-B; SPEC OQ-36 |
| Prefetches issued per demand sector | snake_pf_issued / snake_demand_sector_accesses | our stats |
| Unused share of issued | (issued − timely − late) / issued: evicted unused plus never used by the end | our stats (SNAKE_PLAN §7 outcome invariant) |
| L1 hit rate | Total_core_cache_stats_breakdown[GLOBAL_ACC_R][HIT] / [TOTAL_ACCESS] | sim.out |
| Summary rows | IPC: GMEAN of gains; '7 apps' combines an app's inputs by GMEAN first (hotspot, lud). Coverage, accuracy and the other rates: unweighted arithmetic mean over the workloads that have a value (over apps, inputs first, in the '7 apps' row); a workload with nothing to divide (e.g. nw, no prefetch used) is skipped | this script |
